    Create SQL migrations for the RBAC schema based on RESEARCH.md Pattern 4:
    
    001_initial_schema.sql:
    - Create app_role enum ('admin', 'operator')
    - Create user_roles table:
      * id (bigint, primary key)
      * user_id (uuid, references auth.users, unique)
      * role (app_role, default 'operator')
      * created_at (timestamptz)
    - Create machine_assignments table:
      * id (bigint, primary key)
      * operator_id (uuid, references auth.users)
      * machine_id (text) - ESP32 device ID
      * created_at (timestamptz)
      * unique constraint on (operator_id, machine_id)
    - Enable RLS on both tables
    
    002_rls_policies.sql:
    - Policy: "Users can read own role" on user_roles
    - Policy: "Admins can read all roles" on user_roles
    - Policy: "Admins can insert/update roles" on user_roles
    - Policy: "Operators see assigned machines" on machine_assignments
    - Policy: "Admins can manage all machine assignments" on machine_assignments
    
    Use the exact SQL patterns from RESEARCH.md Section "Pattern 4: Database Schema for RBAC".
